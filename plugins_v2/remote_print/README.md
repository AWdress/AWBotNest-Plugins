# 远程打印

AWBotNest V2 插件。平台在服务器或 Docker 中接收 Telegram / 企业微信文件，默认通过 IPP 向局域网打印机提交任务，可借助已有 FRP 隧道连接；不要求 Windows 电脑运行打印端。也可切换为 Windows 电脑主动领取模式。不修改平台、FRP 配置或系统默认打印机。

## 企业微信接收地址（使用企微必看）

插件使用平台统一的企业微信回调。照片、PDF、文字操作与平台的 `/插件`、`/运行` 命令可以使用同一个自建应用；绑定企业成员身份的微信插件/微工作台也沿用这个回调。企微与普通微信每个新文件只发一条文字确认，0.0.10 的旧卡片仍可控制它对应的任务。

```text
https://你的平台域名/api/wecom/callback/{channel_id}
```

填写位置：企业微信管理后台 → 应用管理 → 你的自建应用 → 接收消息 → 设置 API 接收。

`{channel_id}` 要换成平台中的企业微信渠道 ID，不能原样复制。使用平台该渠道提供的完整回调地址；部署在子路径时也要带上子路径。Token、EncodingAESKey 使用平台对应渠道中的值，由平台校验和解密。

在平台“插件通知设置”中，为“远程打印”**显式关联一个企业微信自建应用**。只设置默认应用，或平台中只有一个应用，都不足以启用打印接收；群机器人不支持。再在平台该渠道开启消息回调、授权成员，并在插件填写允许打印的成员名单。

在插件保存“平台访问地址”后，点“查看平台企微回调地址”可查看关联应用的完整接收地址。这个字段只帮助显示完整 URL，不是开启企微收件的条件。**如果曾按 0.0.8 把企微后台改为 `/api/plugin/remote_print/wecom`，升级后请换回平台的 `/api/wecom/callback/{channel_id}`。** 本版不再提供旧的打印专用回调。只用 Telegram 无需设置企微回调。

0.0.12 的 Vue 配置页分为“打印设置 / 家人权限 / 任务与工具 / 使用帮助”四个页签。常用设置直接显示，长说明按需展开，高级参数默认收起；底部统一保存，切换分类不会丢失填写内容。管理工具直接展示可复制的回调地址、设备状态和任务详情，失败也显示具体提示。工具仅通过平台鉴权的管理员接口调用，不作为公开 Webhook，也不会在打开页面时执行。配置默认值、密钥眼睛和危险操作确认保留，插件不修改平台页面或打印逻辑。

## 支持范围

- PDF 文档、JPG/JPEG、PNG、WebP、BMP 单张图片；Office 文档请先另存为 PDF。
- Telegram：使用平台绑定或默认 Bot，仅接收允许用户的私聊，不监听群里的文件；断线恢复或切换平台绑定后自动重新接入。
- 企业微信：通过平台统一回调接收自建应用的文件和文字指令，旧卡片操作保留；必须显式关联应用，群机器人不支持。每个文件最多 20 MiB，插件设置更低上限时按更低值限制。
- 普通微信：通过企业的“微信插件/微工作台”进入自建应用，按绑定的企业成员 UserID 授权；使用文字提示确认打印。本插件不接入任意公众号、个人微信聊天或客户联系。
- IPP 模式：固定连接一台支持 IPP Print-Job 的打印机。打印机需原生支持 PDF / JPEG；PNG、WebP、BMP 自动转换为单张 JPEG。图片明确使用 `print-scaling=fit`，保留完整内容和原图比例，不裁切、不拉伸；比例与纸张不同会留白，长图缩小到一页，不自动拆页。设备未声明支持 `fit` 时拒绝图片任务，不改用 `auto` / `fill`。PDF 保持原文档页面，不改变其版式。
- Windows 模式：一台 Windows 10/11 电脑，可选择它允许列表内的多台打印机，电脑端需 Python 3.10+。彩色/双面/纸张/指定页码的远程参数暂不提供，使用打印机默认设置或本地驱动设置。

## 1. 配置服务器插件

安装插件后，在插件配置页填写（管理工具需要先启用插件）：

1. 在“连接打印机”选择“直接连接网络打印机（推荐）”，填写“打印机访问地址”，必须是服务器或容器能访问的 HTTP(S) 地址，包含打印路径，例如 `http://打印机IP:631/ipp/print`。同一局域网不需要 FRP；使用 FRP 时替换映射主机和实际端口，保留打印路径。这里不填平台域名，也不填 `ipp://`。只能通过电脑打印时，改选“通过 Windows 电脑打印”，按下节配置电脑端。
2. 企微需要查看完整回调地址，或使用 Windows 电脑端时，填写“平台访问地址”，例如 `https://bot.example.com`。如反代部署在子路径，可以填写 `https://bot.example.com/aw`。企微收件不依赖此字段，后台使用上方的平台统一回调地址；插件不会自动修改企微后台。仅 Telegram + IPP 时可留空。
3. Telegram Bot 和企业微信自建应用在**平台系统设置**配置，不在插件重复填写凭据。企微还需在平台“插件通知设置”中为“远程打印”显式关联一个自建应用。插件这里只填写允许打印的用户；对应名单留空时拒绝该渠道所有人。
4. 保存后检查连接，再开启“接收打印文件”。“收到文件直接打印（不需要确认）”默认关闭，推荐保持关闭：发文件后回复“打印”才开始。Telegram 也可点“打印一份”；企微与微信不重复发卡片。

保存后插件按平台机制重载。IPP 模式先点击“检查能否连接打印机（不打印）”，读取名称、状态和支持格式；该按钮不会发送打印任务。需要特殊连接参数时打开“显示高级设置”，“打印机内部地址”通常留空，自动使用设备报告的 URI；若 FRP 下设备拒绝探测，可填写打印机自身的 `ipp://局域网IP:631/ipp/print`，这与服务器访问地址是两个不同字段。

“查看打印机与接收地址”显示设备状态及电脑端连接地址；“查看平台企微回调地址”显示关联应用的统一回调地址与填写步骤。Token / EncodingAESKey 在平台渠道中查看，插件按钮不显示密钥，详见下方企微设置。

默认每次 1 份，最多 3 份；每个文件最多 20 MiB、50 页，最多 30 个未结束任务，缓存最多 200 MiB，保留 24 小时。文件上限可设为 1～25 MiB，Telegram 按该设置限制；企微受平台下载接口限制，最高 20 MiB，设置低于 20 MiB 时按更低值限制。高级参数默认收起，打开“显示高级设置”后查看或修改。所有开关默认关闭，电脑密钥独立隐藏并可点眼睛查看。切换连接方式或收起高级设置不会删除已保存的另一种模式和高级参数。

配置页逐项显示中文说明和默认值，只补缺失的键，不覆盖已保存的空值、地址、名单或密钥。未保存的修改不会被管理按钮自动保存；请先保存再执行工具。读取配置失败时禁止保存，避免误覆盖原配置。启用加载插件不等于开启接收或自动打印。地址、家人名单及密钥必须按自己的环境填写，示例不会作为真实配置自动保存。清理缓存、归档待核查任务和更换电脑密钥均需再次确认。

网络直连模式每 3 秒检查有没有已确认的打印任务；Windows 模式由电脑端主动领取任务，默认每 5 秒一次。两种模式均每 10 秒检查机器人连接，每 1 分钟检查到期文件。它们是检查频率，不是反复打印的频率；同一任务不会因为轮询而重复提交。平台状态页右侧的“1分钟后”可能是把不足一分钟的剩余时间向上取整，实际间隔以任务标题下的“每 3 秒 / 每 10 秒 / 每 1 分钟”为准。

### FRP 与 Docker 注意事项

FRP 在局域网端转发打印机的 TCP 631 端口。以下假设打印机地址为 `192.168.1.50`，frpc 的 TCP 代理示例为（地址和端口需替换）：

```toml
[[proxies]]
name = "printer-ipp"
type = "tcp"
localIP = "192.168.1.50"
localPort = 631
remotePort = 1631
```

这只是代理条目示例，不包含你的 frpc 服务器和鉴权配置。frpc 需运行在能访问打印机的局域网设备上，设备与打印机都需在线。现有 FRP 如已映射无需重复配置，插件填写它实际提供的 HTTP 访问入口和 `/ipp/print` 路径即可。

**不能把无鉴权 IPP 端口裸露到公网。** FRP token 只保护隧道连接，不能阻止别人访问公开映射端口。应让 frps 打印端口仅绑定内部/回环地址，或用防火墙仅放行平台的可信来源；也可使用已有受限私网隧道。插件不会自动配置 FRP、绑定地址或防火墙。HTTP 只能用于可信内部链路，跨不可信网络应提供有效证书的 HTTPS 入口。

Docker 的 `127.0.0.1` 是容器自身，不是 VPS 宿主机。填写容器能访问的宿主机私网地址或已有网关，并确保防火墙放行该容器来源。若平台配置了 HTTP 代理，IPP 请求也走平台代理；代理所在设备也必须能访问这个入口。远端代理无法访问 VPS 内部入口时，需要调整现有网络或平台代理设置，插件不会自行绕过代理或修改平台。

## 2. 配置 Windows 打印端

只有选择“通过 Windows 电脑打印”时才需要本节。填写电脑端设备名称（默认 `home-printer`），生成电脑端连接密钥，刷新配置页用眼睛读取，再复制到电脑端。至少 32 个无空格 ASCII 字符，不能使用平台管理员密码。

将插件包中的整个 [`agent`](agent/README.md) 目录复制到连接打印机的电脑，按 [Windows 打印端说明](agent/README.md) 安装依赖、填写 `config.json` 并运行。

电脑端与插件的 `device_id` / 密钥必须一致；`allowed_printers` 填写 Windows 中的完整打印机名称。“电脑上使用哪台打印机”留空时使用电脑端选出的默认打印机；如填写，必须在电脑端允许列表中。

接收端的 `--list-printers` 只读打印机列表，`--check` 只检查依赖、权限、握手，不打印。`--once` 可能实际打印一个已确认任务，不要当作只读测试。

默认只接受 HTTPS 且校验证书，不跟随跳转，不使用电脑的环境代理。反代必须直接转发这些地址，不能跳到登录页：

```text
POST https://你的平台域名/api/plugin/remote_print/agent
GET  https://你的平台域名/api/plugin/remote_print/agent_file
```

每个设备只能运行一个接收端，不能复制设备密钥到另一台电脑并行运行。不要删除、修改或回退电脑端的 `journal.json`，否则会破坏防重复提交的依据。平台同一队列也不能多进程/多容器共享同一个数据目录。

## 3. Telegram 使用

先连接平台 Bot，在允许列表填写数字用户 ID。插件使用平台为它绑定的 Telegram 渠道，未绑定时读取平台默认 Bot；无需插件再填 Bot Token。

日常使用只需两步：**发照片或 PDF → 点“打印一份”**。收件消息同时提供“打印两份”“取消打印”“查看进度”；管理员限制最多一份时不显示两份按钮。默认不自动打印，重复点击不会重复提交。

也可以直接回复“打印”“打印两份”“取消”“进度”，不用记任务编号。只有一个合适的文件时才执行；同时有多个待处理文件时不会猜测，请点具体文件上的按钮。收到文件不等于开始打印，“已提交打印”不等于已经出纸。

Bot 启动时离线、断线恢复、更换客户端或平台绑定时，插件每 10 秒检查并重新接入，不需要手动重载。不可用或停用的绑定不会改接其他 Bot；切换绑定后旧 Bot 的消息不再接受。

### 高级命令

需要指定份数或 Windows 打印机时，发送 `/print_help` 查看编号命令：

```text
/print 任务ID
/print 任务ID 2
/print 任务ID 2 打印机完整名称
/print_cancel 任务ID
/print_jobs
/printers
```

也可发送中文命令：“打印 任务ID”“取消 任务ID”“任务”“打印机”“帮助”。只允许操作自己创建的任务。只有 Windows 模式可以在命令中指定打印机名称；IPP 使用管理员配置的固定打印目标。需要图片原始分辨率时，请作为文件发送，避免 Telegram 压缩图片。

## 4. 企业微信自建应用

在**平台系统设置 → 通知渠道**配置企业微信自建应用的 CorpID、AgentID、Secret，以及已有的企业微信 API 中转地址（如使用）。再在平台“插件通知设置”中为“远程打印”显式关联准备使用的一个自建应用；默认应用或唯一应用不能代替关联。请只关联一个企微应用，群机器人不支持。

在平台该企业微信渠道中开启“消息回调”，填写回调 Token 和 EncodingAESKey（配置字段为 `callback_token`、`callback_aes_key`），并授权允许操作的成员。平台负责回调校验、解密和分发，插件不生成、回写或另存密钥；缺少配置或平台关闭回调时不能接收。需要查看密钥时，在平台渠道中点眼睛；插件按钮、状态和日志不展示密钥。

在插件填写允许打印的**成员 UserID**，不是昵称或手机号；成员还必须在平台回调的授权名单中，两处都允许才接收。与平台最新规则一致，UserID 不区分大小写，回执保留原始 ID；不同应用的同名成员仍然隔离。平台名单用 `|` 分隔，插件名单每行一个或逗号分隔。平台支持官方生成的合法 43 字符 EncodingAESKey。若从 0.0.3 升级，请先把当时插件生成的回调密钥填入平台；插件不再读取旧密钥，启用时会移除旧渠道配置字段。

平台校验签名、AES 密文、企业 ID、应用 ID、时间戳和成员身份，再将授权消息交给插件。插件检查关联应用和打印成员名单，不接收未鉴权的消息。

企业微信后台“接收消息”填写：

```text
https://你的平台域名/api/wecom/callback/{channel_id}
```

替换为实际渠道 ID；反代位于子路径时带上子路径。配置页“查看平台企微回调地址”提供关联应用的地址与填写步骤。Token / EncodingAESKey 与平台渠道填写的一致。验证接收 URL 时可以关闭插件“接收打印文件”，但需开启平台消息回调。

**统一回调同时支持平台的 `/插件`、`/运行` 命令与打印消息，无需切换应用或单独设置打印接收 URL。** 0.0.8 使用过打印专用地址的用户，升级后必须换回此平台地址。

应用可见范围需包含允许成员，按企微后台要求配置服务器出口可信 IP。成员在**自建应用会话**中发照片或 PDF。关闭自动打印时，每个新收取的待确认文件只发送一次分段文字提示；回复“打印”（1 份）、“取消”“进度”，管理员允许打印两份时也可回复“打印两份”。普通照片显示为“图片.jpg”等可读名称，不显示无意义的长 MediaID；真实文件名称保留，过长时仅在聊天展示中缩略。

只有一个合适的文件时，直接回复上述文字即可；多个未结束文件时不会自动选择最新文件，请使用文字提示中的任务编号，例如“打印 任务ID 1”“取消 任务ID”。“任务”“打印机”和其他编号命令与 Telegram 一致。文字发送失败时不反复推送，也不会因此自动确认或打印；任务仍可在管理员页面查看。此前已发出的企微卡片按钮仍可操作原任务。

### 微信插件/微工作台

普通微信用户先关注本企业提供的“微信插件/微工作台”，并绑定自己的企业成员身份，再从该企业的应用入口进入自建应用会话。管理员授权的是企业通讯录中的**成员 UserID**，不是微信昵称或微信号；同一个 UserID 必须同时加入平台回调名单与插件打印名单。无需额外配置微信回调，仍使用本应用的平台统一回调。

微信插件/微工作台使用文字提示操作：发照片或 PDF 后，只有一个合适的文件时回复“打印”；需要两份且管理员允许时回复“打印两份”，也可回复“取消”“进度”。有多个文件时，按提示中的编号操作，避免选错文件。

企业微信[官方模板卡片接口说明](https://developer.work.weixin.qq.com/document/path/90236)明确微工作台不支持模板卡片；普通消息回调也没有可靠的微信/企微客户端标识。0.0.11 因此统一只发文字确认，既保留微信正常操作，也避免企微收到文字与卡片两份提示。旧卡片与文字确认仍使用同一任务队列，重复消息不会重复打印。

请在企业微信管理后台检查该应用的微工作台设置，**不要开启“在微工作台中始终进入主页”**。官方说明此设置会把微信端文字消息截断为最多 20 字节，完整的确认提示和任务编号将无法显示；插件不能改变这一微信端限制。

这个入口只面向已绑定的企业成员，不代表支持任意公众号会话、个人微信聊天或企业的客户联系。

回调快速确认，下载、打印与消息回执在后台处理。回执只发给原始上传人，不使用平台渠道的 `@all` 群发目标。切换应用不会把旧任务回执发送到其他应用；撤销成员权限后不接受其后续操作。企业微信应用主动发送消息没有配置好时，任务状态仍保存，可在管理员“查看最近的打印任务”中查询。

媒体使用平台 SDK 的鉴权下载接口，只按消息中的 MediaID 从平台配置的固定 `media/get` 接口获取，不使用 PicUrl 或用户提供的下载地址，也不跟随重定向。每个文件最多 20 MiB，插件设置更低上限时按更低值限制；下载期间撤销授权或变更应用配置也会停止。

待确认文件的文字提示使用平台应用配置及 HTTP 服务发送，不再生成新企微卡片；获取凭据后再次检查插件开关、成员权限和应用配置。发送提示本身不会启动打印。

图片在收件时完整解码，坏 JPEG 不再先进入待确认队列；IPP 提交前统一转成 RGB 普通 JPEG，纠正 EXIF 方向，透明区域铺白，不裁切或拉伸。设备声明 JPEG 最大尺寸时，超尺寸图片完整等比缩小；不能满足最小尺寸或编码后的文件大小范围时明确拒绝，不猜测设备上限、不静默降低质量。打印失败/结果待核查时，聊天、任务详情与日志显示受限的具体原因；明确拒收会记录 IPP 状态码及不支持的参数名，不显示服务地址、密钥或原始响应。旧版本日志只有“失败”的任务，无法凭旧日志还原当时原因，请从升级后的任务详情查看已保存原因。

## 状态、取消与恢复

| 状态 | 含义 |
| --- | --- |
| 等待确认 | 已收到合法文件，未授权打印 |
| 等待打印 | 已确认，等待 IPP 提交或电脑端领取 |
| 正在准备打印 | 检查设备能力、验证文件并转换图片；此时可取消 |
| 正在提交打印 | 已持久保存一次性提交许可；不能保证远程取消 |
| 已提交打印队列 | 打印机或 Windows 打印系统接受了任务，**不代表纸张已经打印完成** |
| 失败 | 未能完成任务；不会自动重打，请检查后重新发文件 |
| 结果待核查 | 网络/重启/提交异常，无法确定是否已经出纸；不会自动重打 |

领取准备超过 5 分钟或平台在准备阶段重启时，任务结束为失败，不再重复授权同一任务。提交后超过 10 分钟未收到回执，任务标记为待核查，迟到的有效回执仍可确认结果。打印端重启只补报已有结果；有歧义时停止该任务的重打，其他新任务仍可正常执行。

取消仅作用于尚未开始提交的任务，不控制已经交给打印机或 Windows 的打印队列。卡纸、缺纸、打印机断线及已提交任务的取消，请在打印机或 Windows 打印队列上处理。IPP 提交超时、回执损坏、连接中断或提交时停用插件，一律标记待核查，不自动重试。切换模式、设备或 IPP 地址不会把旧排队任务改投新的打印机，请重新发送文件。

待核查任务也占活动数量，防止故障任务无限堆积。先检查打印队列和实际出纸，再在管理页点“已人工核查的任务归档（不重打）”解除容量占用；该按钮不重打，也不取消打印机中的任务。清理按钮删除已结束任务的本插件缓存，不取消打印机队列；待核查文件仍会在保留期限后清理，待核查记录继续保留。未及时确认/打印的排队任务到期取消。

不要启用自动打印后允许陌生用户上传文件。文件大小/页数/像素限制不能代替 PDF 解码器的进程级安全沙箱，本版仅适合授权的可信用户。
