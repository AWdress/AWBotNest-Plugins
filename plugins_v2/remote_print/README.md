# 远程打印

AWBotNest V2 插件。平台在服务器或 Docker 中接收 Telegram / 企业微信文件，打印机所在的 Windows 电脑主动领取任务并打印。电脑不用公网 IP，不需要开放端口；**电脑与打印机必须在线，并运行随插件提供的打印端**。不修改平台或系统默认打印机。

## 支持范围

- PDF 文档、JPG/JPEG、PNG、WebP、BMP 单张图片；Office 文档请先另存为 PDF。
- Telegram：使用平台已连接的默认 Bot，仅接收允许用户的私聊，不监听群里的文件。
- 企业微信：企业自建应用的加密消息回调；群机器人不能接收用户上传文件，不适用于远程打印。
- 一台 Windows 电脑，可选择它允许列表内的多台打印机。服务器插件支持 Windows/Linux；电脑端支持 Windows 10/11，Python 3.10+。Linux 本地打印端、彩色/双面/指定页码的远程参数暂不提供，纸张、方向、单双面使用本地驱动设置。

## 1. 配置服务器插件

安装并启用插件后，在原生配置页填写：

1. 平台外网 HTTPS 地址，例如 `https://bot.example.com`。如反代部署在子路径，可以填写 `https://bot.example.com/aw`。
2. 电脑端设备 ID，默认 `home-printer`。点击“生成 / 更换电脑端密钥”，刷新配置页，用眼睛查看密钥，复制到电脑端。至少 32 个无空格 ASCII 字符，不能使用平台管理员密码。
3. 开启需要的消息渠道，并填写用户允许列表。所有功能开关默认关闭，未填写允许列表时不接受任何用户。
4. 开启“接收远程打印任务”。“收到文件后自动打印”默认关闭：收件后需要单独确认。

保存后插件按平台机制重载。点击“查看连接地址与打印机”可以查看实际企微 Webhook、电脑端地址及允许的打印机。默认份数 1，最多 3 份；默认文件 20 MiB、50 页、30 个活动任务、总存储 200 MiB，文件保留 24 小时。字段值在原生表单中显示；Secret、AES Key 和电脑密钥独立隐藏，可以点眼睛查看。

## 2. 配置 Windows 打印端

将插件包中的整个 [`agent`](agent/README.md) 目录复制到连接打印机的电脑，按 [Windows 打印端说明](agent/README.md) 安装依赖、填写 `config.json` 并运行。

电脑端与插件的 `device_id` / 密钥必须一致；`allowed_printers` 填写 Windows 中的完整打印机名称。插件“默认目标打印机”留空时使用电脑端选出的默认打印机；如填写，必须在电脑端允许列表中。

接收端的 `--list-printers` 只读打印机列表，`--check` 只检查依赖、权限、握手，不打印。`--once` 可能实际打印一个已确认任务，不要当作只读测试。

默认只接受 HTTPS 且校验证书，不跟随跳转，不使用电脑的环境代理。反代必须直接转发这些地址，不能跳到登录页：

```text
POST https://你的平台域名/api/plugin/remote_print/agent
GET  https://你的平台域名/api/plugin/remote_print/agent_file
```

每个设备只能运行一个接收端，不能复制设备密钥到另一台电脑并行运行。不要删除、修改或回退电脑端的 `journal.json`，否则会破坏防重复提交的依据。平台同一队列也不能多进程/多容器共享同一个数据目录。

## 3. Telegram 使用

先连接平台 Bot，开启 Telegram 打印，在允许列表填写数字用户 ID。给 Bot 私聊发 PDF 或图片，会得到任务 ID 和状态。

```text
/print 任务ID
/print 任务ID 2
/print 任务ID 2 打印机完整名称
/print_cancel 任务ID
/print_jobs
/printers
```

也可发送中文命令：“打印 任务ID”“取消 任务ID”“任务”“打印机”“帮助”。只允许操作自己创建的任务。需要图片原始分辨率时，请作为文件发送，避免 Telegram 压缩图片。

## 4. 企业微信自建应用

在插件中填写 CorpID、AgentID、应用 Secret、回调 Token、EncodingAESKey，填写允许的**成员 UserID**，不是昵称或手机号。插件校验签名、AES 密文、企业 ID、应用 ID、时间戳和成员身份，不支持未签名明文回调。

企业微信后台“接收消息”填写：

```text
https://你的平台域名/api/plugin/remote_print/wecom
```

如果反代位于子路径，请加上子路径；配置页“查看连接地址与打印机”提供按配置拼接的地址。Token / EncodingAESKey 必须与插件一致。配置 URL 验证时可以关闭“接收远程打印任务”，但需要开启“企业微信打印”。

应用可见范围需包含允许成员，按企微后台要求配置服务器出口可信 IP。成员在**自建应用会话**中发送文件/图片后，再发送“打印 任务ID”确认；“任务”“打印机”“取消 任务ID”与 Telegram 一致。回调快速确认，下载、打印与消息回执在后台处理。企业微信应用主动发送消息没有配置好时，任务状态仍保存，可在管理员“查看最近打印任务”中查询。

媒体只从官方固定 `media/get` 接口获取，不接受用户输入的下载 URL。下载使用平台的有大小上限流式服务，该服务内部会跟随官方媒体重定向。

## 状态、取消与恢复

| 状态 | 含义 |
| --- | --- |
| 等待确认 | 已收到合法文件，未授权打印 |
| 等待电脑领取 | 已确认，电脑离线时排队 |
| 电脑正在准备 | 下载、验证文件哈希并渲染；此时可取消 |
| 正在提交打印 | 已给电脑一次性提交许可；不能保证远程取消 |
| 已提交打印队列 | Windows 打印系统接受了任务，**不代表纸张已经打印完成** |
| 失败 | 未能完成任务；不会自动重打，请检查后重新发文件 |
| 结果待核查 | 网络/重启/提交异常，无法确定是否已经出纸；不会自动重打 |

领取准备超过 5 分钟或平台在准备阶段重启时，任务结束为失败，不再重复授权同一任务。提交后超过 10 分钟未收到回执，任务标记为待核查，迟到的有效回执仍可确认结果。打印端重启只补报已有结果；有歧义时停止该任务的重打，其他新任务仍可正常执行。

取消仅作用于尚未开始提交的任务，不控制已经交给 Windows 的打印队列。卡纸、缺纸、打印机断线及已提交任务的取消，请在 Windows 打印队列或打印机上处理。

待核查任务也占活动数量，防止故障任务无限堆积。先检查打印队列和实际出纸，再在管理页点“待核查任务归档（不重打）”解除容量占用；该按钮不重打，也不取消打印机中的任务。清理按钮只删除已结束任务的本插件文件，保留任务记录。已结束文件超过保留时间自动删除；未及时确认/打印的排队任务到期取消。

不要启用自动打印后允许陌生用户上传文件。文件大小/页数/像素限制不能代替 PDF 解码器的进程级安全沙箱，本版仅适合授权的可信用户。

## 验证范围

已在 Windows 做 SDK 存储/路由、真实本机 HTTP 领取、PDF/图片实际渲染、签名 AES 回调、权限、并发、重复请求、断线和重启恢复测试；打印提交使用模拟后端。真实 Windows 打印机枚举及驱动参数只读检查通过。**未使用用户的 Telegram/企业微信真实应用联调，也未进行物理出纸测试**，安装后请先用一页 PDF、1 份人工验证。
