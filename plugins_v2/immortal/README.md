# Immortal

AWBotNest V2 内置版。业务源码和管理台随插件运行，不需要再启动 Immortal 容器、HTTP 端口或独立机器人。

## 首次使用

1. 安装并启用插件，打开配置页的「管理页面」。
2. 在管理页面设置采集相关地址、下载器和媒体服务器，保存后再手动测试。
3. 需要定时运行时，在「插件设置」开启「运行自动任务」，并在管理页面创建、启用具体任务。默认全部关闭，任务间隔至少一小时，使用北京时间。
4. 需要下载时，另行开启「允许提交下载」。创建影片、演员或综合订阅本身不会立即下载。

「运行状态」可查看当前排队和执行的任务，也可请求停止任务。历史结果在管理页的任务执行日志中查看。正在发送的下载请求会先等待返回；停止不是撤销已被下载器接受的任务。

## 数据与配置

安装后自动在平台分配给插件的数据目录创建独立 SQLite 数据库，保存 `immortal.sqlite3` 与 `download-receipts.sqlite3`；不用另装或配置数据库，也不会使用或修改平台数据库。请将平台的数据目录持久化，备份时包含这两个文件。

管理台的采集、订阅、规则和下载器配置存入插件数据库；「插件设置」中的三个开关与外部数据库地址存入平台插件配置。这两部分都需要各自保存。

已有 PostgreSQL 可在「插件设置」填写连接地址并安装 `psycopg2-binary`。切换连接地址不会搬迁数据；不要填写平台数据库。当前本地回归主要验证 SQLite，未验证真实 PostgreSQL 部署。

## 功能范围

保留资源、影片、演员、榜单、规则、过滤和优先级、影片／演员／综合订阅、下载历史、表格导入导出及业务任务。

下载器支持 qBittorrent、Transmission、迅雷及 CloudDrive；媒体查询支持 Emby、Jellyfin、Plex 和极影视。外部组件需要能从平台服务器访问。CloudDrive 选用时需要 `grpcio>=1.76,<2` 和 `protobuf>=6.31.1,<7`。

1080X 与 JavLibrary 采集需要可访问的 FlareSolverr，在管理台「采集连接设置」中填写其地址。这是相应采集站的浏览器验证依赖，不是另行运行 Immortal。

通知使用平台已有渠道，不另起 Telegram／Discord／企业微信机器人。原独立登录、API 令牌管理、SQL 执行、PageAgent、服务器文件清理、Docker 更新入口不开放。

表格上传在平台桥接层限制为 6 MB（包含上传封装），导出响应最多 8 MB；XLSX 解压总量最多 64 MiB，每次导入最多 50000 行。

## 下载结果

每个资源链接记录提交回执，重复请求不重复提交。网络超时或异常中断可能表示远端已接受但本地未收到响应，此时显示“结果未确认”，不会自动重发。请先到下载器确认实际状态。

体积探测不新增或删除种子；媒体库查询失败不会被当成“影片不存在”。自动功能和下载默认关闭，启用插件不会自动访问采集站或下载器。
