# VPS-Widget

AWBotNest V2 的影视榜单插件，参考 [MakkaPakka518/VPS-Widget](https://github.com/MakkaPakka518/VPS-Widget) 的产品功能与公开数据接口，使用独立实现的 Python 采集器和 Widget 生成器。不是 VPS 监控工具，也不启动独立 Node 服务或额外端口。

版本：`0.0.1`。需要 Python 3.11 或更新版本，适用于 AWBotNest V2。

## 第一次使用

1. 从 V2 插件市场安装 **VPS-Widget**，启用插件后打开配置页。
2. 在“配置”填写 **TMDB 密钥**，支持 v3 API Key 或 v4 API Read Access Token。选择榜单来源，保存配置。
3. 在“榜单状态”点击 **更新全部榜单**，或单独更新某个来源。更新在平台后台执行，离开页面不会停止。
4. 需要客户端读取时，填写**平台访问地址**，例如 `https://bot.example.com`；有部署子路径需带上，不要填 `/api` 路径。开启“允许客户端读取 Widget”，保存。
5. 在“Widget 地址”获取并复制地址，导入 Forward 的 Widget 模块。

输出采用 Forward 的 Widget 格式，每页 24 条，支持榜单顺序、最近更新、最近上映、热度、评分排序。Rex、Capy 等客户端以其当前版本的导入支持为准；未在这些客户端中作实际运行验证。

## 来源与设置

支持骨朵、豆瓣、芒果 TV、剧场片单、Bangumi、TMDB、B站、MyAnimeList、AniList、Trakt。B站只展示有实际数据的番剧和国创；剧场可选择全部、已开播或即将开播。只有匹配到 TMDB ID 和海报的条目会进入榜单，未匹配数量在状态中显示。

- 每分类默认最多采集 **30 条**，可设置 10～100 条。源站榜单不足时返回实际数量；采集数不是匹配成功数。
- **自动更新默认关闭**。开启后每天北京时间 **17:00** 更新，可更改时分。不进行秒级或分钟级空轮询；关闭时启用插件不会自动抓取，开启后遵循平台的定时与延迟补执行规则。
- **通知默认关闭**，开启后使用平台已关联的通知渠道。
- Trakt 另需应用的 **Client ID**，不是 OAuth Access Token。留空只跳过 Trakt，其余来源正常执行。
- 公开读取默认关闭；不开启时仍能在管理员配置页更新和预览榜单。
- 配置保存使用完整字段；仅补缺失的默认值，不覆盖关闭开关或用户清空的文本。保存配置会由平台安全重载插件，正在运行的更新会被停止，建议先等待更新结束。

## 更新与故障处理

使用 `ctx.http`，继承平台配置的代理，保留 TLS 证书校验。单次请求最多等待 25 秒、最多读取 5 MB；源站分页与条数有硬上限，TMDB 匹配最多 4 个并发。每来源最多运行 6 分钟，一轮最多 30 分钟。数量越多，更新越慢，超时后可降低每分类条数再重试。

同一时间只运行一轮更新。只有某个来源完整采集、匹配且保存成功，才替换该来源的旧榜单；网络错误、响应异常、没有有效匹配或中断时保留旧缓存。可以停止当前更新，稍后单独重试失败来源。来源禁用不会删除已有缓存，但客户端不能读取禁用的来源。

TMDB 成功匹配缓存 7 天，未匹配缓存 6 小时，最多保留 2500 个匹配记录，且按 UTF-8 大小限制在 8 MB 内。列表简介最多 1000 字符；完整详情由客户端查询 TMDB。最近更新排序使用剧集最新一集播出日期，不把采集时间伪装成影片更新时间。

源站可能限流、要求登录或改变接口。状态页会显示每来源的真实结果，外部网站故障不报告为更新成功。遇到证书或网络错误，请检查平台代理与证书链，不建议关闭证书校验。

## Widget 地址与安全

公开只读入口如下，地址由插件自动生成，请直接复制完整地址：

```text
https://你的平台域名/api/plugin/vps_widget/widget.js?token=独立只读密钥
https://你的平台域名/api/plugin/vps_widget/data/来源ID.json?token=独立只读密钥
```

公开路由只接受 GET，并核对插件开关与独立只读密钥。不会公开 TMDB/Trakt 密钥，也不能从公开地址触发更新。缓存响应支持 ETag；Widget 只读取缓存，不在播放器里抓取榜单源站。

**地址含有只读凭据，不要公开分享。** 导入模块内也会包含这个只读凭据。反代访问日志可能记录查询参数，建议不要长期记录这些 URL，且优先使用 HTTPS。地址泄露时在“Widget 地址”更换只读密钥，所有旧地址立即失效，客户端需要重新导入。

使用平台现有 Webhook 路由，无需另外配置服务器端口。插件停用后路由与定时任务由平台移除，后台更新取消，缓存保留在插件自己的存储中。
