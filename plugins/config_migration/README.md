# V1 配置迁移源

配合 AWBotNest 2 的“配置迁移助手”，一次性导出 V1 的系统配置和插件状态。

1. 在 V1 系统设置中确认已设置 `WEBHOOK_SECRET`。
2. 安装本插件，设置至少 8 位的一次性迁移码和有效时间，然后启用。
3. 立即打开 V2 的“配置迁移助手”，填写 V1 地址、Webhook 密钥和相同迁移码。
4. 成功读取一次后迁移码立即失效。迁移结束后请停用或卸载本插件。

可迁移系统、通知渠道、AI 服务、CookieCloud、插件配置、启用状态、账号范围和 Bot 路由；V2 不再使用的旧数据库与 ngrok 配置不会迁移。

导出内容可能包含敏感配置，只应通过可信内网或 HTTPS 传输。插件不会在日志中输出迁移内容。
